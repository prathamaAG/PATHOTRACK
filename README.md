# 🩺 PathoTrack - Laboratory Management System

A comprehensive web application for pathology laboratories to manage patients, tests, reports, and billing operations.

## 🚀 Features
- Patient management with CRUD operations
- Laboratory test creation and management
- Report generation with PDF export
- Invoice creation and email delivery

## 🛠️ Tech Stack
- **Frontend**: React.js, React Router, Material-UI
- **Backend**: Node.js, Express.js
- **Database**: MongoDB with Mongoose
- **Additional**: Nodemailer, jsPDF, Axios

## 📦 Installation

### Backend
- npm install
- npm start

### Frontend
- cd pathotrack
- npm install
- npm start
